# SYLUTION LTD - AgriTech & Technology Innovation

SYLUTION LTD is a Nigerian technology innovation company applying Artificial Intelligence (AI), Internet of Things (IoT), Electronics, Robotics, and Drone technology to modern agriculture and real-world problems.

Based at the Technology Incubation Centre (TIC), Kano, Nigeria, SYLUTION serves multiple industries with a focus on precision farming, intelligent sensing networks, and custom hardware engineering.

## Key Platforms

- **SYSMART AGRO**: AI + IoT Powered Smart Agriculture platform.
- **SYLUTION ACADEMY**: Practical training in emerging technologies for farmers, youth, and agripreneurs.
- **SYLUTION IoT**: Robust sensing networks and connected devices.
- **SYLUTION AI**: Agricultural intelligence and predictive analytics.

## Technology Stack

- **Framework**: TanStack Start (React)
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language Support**: English, Hausa, French, Arabic, Yoruba, Igbo, and Kanuri.

## Deployment

The project is optimized for deployment on Vercel using the Nitro preset for TanStack Start.
